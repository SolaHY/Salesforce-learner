# SF Learner — Salesforce 認定アドミニストレーター学習ポータル

Salesforce Certified Administrator 資格の合格を目指す学習ポータルです。
洗練されたモダンUIに、ほどよいゲーミフィケーション（成長するキャラクター）を組み合わせています。
React + Vite 製で、学習データはブラウザの localStorage に保存されます（サーバー不要）。

## 学習マップ & 成長キャラクター

- **学習マップ**: 8単元（Agentforce を含む最新範囲）を配点の大きい順に攻略する進行型マップ。各単元で正答率70%以上を取ると**クリア**となり、次の単元が解放される。全クリアで「修了試験（全範囲）」が開放。
- **成長するアバター**: 単元をクリアするたびに、人物アバターが段階的に成長（見習い → アソシエイト → … → AIスペシャリスト → 認定アドミニストレーターの9段階）。眼鏡・襟・ジャケット・ネクタイ・ヘッドセット・社章・認定スターと装いが増えていく。「進捗・実績」で全段階のギャラリーを確認可能。
- **模擬試験**: 全317問を本番想定の約63問×5回分に構成。**公式プラクティステストと同一の46問**＋その**類似問題46問**＋実試験対策問題225問を、ドメインと出典が偏らないよう均等にミックス（合格ライン65%）。
- **ロードマップ**: 合格までの推奨ルートを5フェーズ（全体把握→基礎固め→アプリ領域→反復→総仕上げ）で提示。

## ゲーミフィケーション（控えめ）

- レベル & ポイント（pt）、連続学習日数、連続正解数。
- 実績バッジ8種。
- 単元クリア・レベルアップ・バッジ獲得時のトースト通知と、合格時の紙吹雪。

## 機能

- **問題演習**: 全470問（各単元50問以上）。4択・複数選択に加え、**シナリオ（シミュレーション）形式**を各単元に収録。
  - **選択肢ごとに「なぜ正解 / なぜ不正解か」を解説**。さらに 💡 補足情報（実務Tips・引っかけ注意点）付き。
  - 即時採点・S〜D評価。
- **模擬試験**: 約63問×5回（全317問）。公式プラクティステストと同一の問題は「公式問題」、その論点を別シナリオで問う問題は「類似問題」としてバッジ表示。出題比率は本番準拠（合格ライン65%）。
- **フラッシュカード**: 用語暗記のフリップカード。
- **学習教材**: 各単元の要点まとめ（Agentforce を含む）。
- **進捗・実績**: アバターの成長記録・正答率・連続記録・バッジ・単元別習熟度・演習履歴を可視化。

### 問題数（単元別）

データ分析 60 ／ 設定とセットアップ 55 ／ オブジェクト 56 ／ 自動化 56 ／ 営業・マーケ 55 ／ サービス 55 ／ 生産性 55 ／ Agentforce 78 = **計470問**（うちシナリオ多数）。

Agentforce は試験ガイドの2つの出題項目（①機能とユースケース：ユースケースのシナリオ、AI の使用が適している状況、セキュリティ、エージェント権限のトラブルシューティング／②エージェントビルダーでのプロンプト・指示の管理・更新・インストール：テスト、会話プレビュー）を網羅するよう構成。
`src/data/questions/*.js` に単元ごとに分割されているので追加も容易。

## セットアップ

```bash
npm install
npm run dev      # 開発サーバー (http://localhost:5173)
npm run build    # 本番ビルド (dist/)
npm run preview  # ビルド結果のプレビュー
```

## コンテンツの追加・編集

サンプルコンテンツは `src/data/` にまとまっています。JSON的なJSオブジェクトを編集するだけで増やせます。

- `src/data/domains.js` — 出題範囲の定義
- `src/data/quizzes.js` — 単元別の問題（`src/data/questions/*.js` を集約）
- `src/data/officialQuestions.js` — 模試用: 公式プラクティステストと同一問題（`officialQuestions`）＋類似問題（`similarQuestions`）
- `src/data/mockQuestions.js` — 模試用: 実試験対策サイト由来の問題プール
- `src/data/mockExams.js` — 上記3系統を織り込み、約60問ずつの模試に分割するロジック
- `src/data/flashcards.js` — フラッシュカード（表 `front` / 裏 `back`）
- `src/data/studyMaterials.js` — 学習教材のまとめ

> ⚠️ 同梱のコンテンツは学習用のサンプルです。最新の試験範囲は公式の
> [Salesforce 認定アドミニストレーター試験ガイド](https://trailhead.salesforce.com/credentials/administrator)
> を確認してください。
